@defgroup KW Keywords Reference
@brief Reference for all keywords usable in TRUST `.data` input files.

Keywords are generated automatically from `// XD` tags embedded in the C++ source
code and assembled by the trustify pipeline.  See the **Keywords Reference
Manual** page for the full index.

@defgroup TRUSTUTILS Trustutils Python API
@brief API documentation for the `trustutils` Python package.

`trustutils` provides utilities for writing TRUST validation forms in Jupyter
notebooks.  See the **Validation form API guide** page for the full index.
