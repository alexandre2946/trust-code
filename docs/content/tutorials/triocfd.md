@page Tut_TrioCFD TrioCFD

TrioCFD is an open-source application built on top of the **TRUST** project. 

It specializes in turbulence and multiphase flow modeling at the CFD scale. 
Useful links:
- [Source code on GitHub](https://github.com/cea-trust-platform/TrioCFD-code)
- [Latest documentation on ReadTheDocs](https://triocfd-documentation.readthedocs.io/en/latest).

If you want to build it, you can check their [Quick Start](https://triocfd-documentation.readthedocs.io/en/latest/users/quickstart). You will need to build TRUST first.

After that, you can start experimenting with it by following the [tutorials](https://triocfd-documentation.readthedocs.io/en/latest/tutorials/index.html).
