@page TRUSTTools TRUST Tools

This section lists the satellite tooling that ships with TRUST. These tools
are not part of the simulation engine itself; they help users author, check,
and otherwise work with TRUST datasets and sources.

- @subpage Trustify — Python package that turns the `// XD` keyword
  declarations in the TRUST C++ sources into a `pydantic` schema and a
  matching `.data` file parser. Powers dataset validation, formatting, and
  programmatic editing.

More tools are coming soon.
